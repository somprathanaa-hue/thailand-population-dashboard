# แดชบอร์ดวิเคราะห์สถิติประชากรประเทศไทย (พ.ศ. 2533–2568)

แดชบอร์ดเชิงบริหารสำหรับเปรียบเทียบและวิเคราะห์ข้อมูลประชากรครอบคลุม **77 จังหวัด • กลุ่มอีสานตอนกลาง • 4 ภาค • กรุงเทพมหานคร • ทั่วราชอาณาจักร** โดยบูรณาการข้อมูลจาก 2 แหล่งหลักของประเทศไทย:

1. **ข้อมูลทะเบียนราษฎร (DOPA — กรมการปกครอง):** รายปีต่อเนื่อง 36 ปี (พ.ศ. 2533–2568) นับตามชื่อในทะเบียนบ้าน (*De Jure*) ครอบคลุมประชากรรวม, ชาย–หญิง, สัญชาติไทย–มิใช่สัญชาติไทย และจำนวนบ้าน
2. **ข้อมูลสำมะโนประชากรและเคหะ (Census — สำนักงานสถิติแห่งชาติ):** 4 รอบสำมะโน (พ.ศ. 2533, 2543, 2553 และ 2568) นับตามผู้อยู่อาศัยจริง (*De Facto*) ครอบคลุมประชากรรวม, ชาย–หญิง, เขตเทศบาล–นอกเขตเทศบาล และขนาดครัวเรือนเฉลี่ย

## คุณสมบัติหลัก
- **ตัวกรอง 4 มิติอัจฉริยะ:** เลือกพื้นที่ (รายจังหวัด/กลุ่มจังหวัด/ระดับภาค/ทั่วประเทศ), ปี พ.ศ. (2533–2568), แหล่งข้อมูล (`DOPA vs Census`, `DOPA`, `Census`) และตัวชี้วัดที่สอดคล้องกับแหล่งข้อมูลที่เลือก
- **การ์ดสถิติสำคัญ 5 รายการ:** ประชากรทะเบียนราษฎร, ประชากรสำมะโน, ส่วนต่างประชากรแฝง (Net Migration), สัดส่วนเทียบกลุ่ม/ประเทศ และจำนวนบ้าน (DOPA)
- **กราฟโต้ตอบ (Interactive Charts):** แนวโน้มระยะยาว 36 ปี, กราฟเปรียบเทียบเส้นทะเบียนราษฎรกับจุดสำมะโน 4 รอบ และกราฟวงกลมสัดส่วนประชากรชาย–หญิง/สัญชาติ/เขตเมือง/รายภาค
- **ส่งออกรายงานได้ทันที:** รองรับการดาวน์โหลดไฟล์ **Excel (.xlsx 4 ชีต)**, **CSV** และ **พิมพ์รายงาน/PDF**

## ข้อควรทราบเชิงสถิติ
- **ภาคกลาง (รหัส 2000):** รวม 25 จังหวัดภาคกลางและภาคตะวันออก **ไม่รวมกรุงเทพมหานคร (รหัส 10)**
- **จังหวัดจัดตั้งใหม่:** สระแก้ว, อำนาจเจริญ, หนองบัวลำภู (จัดตั้ง พ.ศ. 2536) และบึงกาฬ (จัดตั้ง พ.ศ. 2554) คงค่าว่างก่อนปีจัดตั้งตามข้อเท็จจริง
- **พ.ร.บ. เปลี่ยนแปลงฐานะสุขาภิบาลเป็นเทศบาล พ.ศ. 2542:** ส่งผลให้สัดส่วนประชากรในเขตเทศบาลตั้งแต่รอบสำมะโน พ.ศ. 2543 เพิ่มสูงขึ้นอย่างมีนัยสำคัญ

1. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น GitHub Repository (ตั้งค่าเป็น **Public**)
2. ไปที่ **Settings → Pages → Build and deployment**
3. เลือก Branch เป็น **`main`** และโฟลเดอร์ **`/ (root)`** แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้รับลิงก์เปิดใช้งานแดชบอร์ดออนไลน์ทันที
